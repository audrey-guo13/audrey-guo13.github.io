Consulting Case Prep.

Fall 2026 recruiting · Crafting Cases + Management Consulted

I'm preparing for MBB recruiting this fall. Rather than memorising frameworks and hoping for the best, I'm using Crafting Cases' six building blocks method — the idea being that casing is a set of discrete, learnable skills, not a set of templates to apply on autopilot. Build the skills well enough and you can handle any case, regardless of industry or type.

Right now I'm working through each block systematically — drills first, then full cases with Management Consulted once the foundations are solid. I'm using AI to stress-test my structure and MECE thinking between practice sessions. This page documents where I am across each block.

Estimations — 8/10, complete for now
Structuring and solving quantitative estimation problems from first principles.
Brainstorming — in progress
Generating MECE, exhaustive lists of ideas under time pressure.
Frameworks — up next
Building custom issue trees tailored to each case, not generic templates.
Analyses — not started
Interpreting and working through quantitative and qualitative data in-case.
Hypothesis Testing — not started
Driving cases forward with a clear point of view rather than exploring aimlessly.
Chart Interpretation — not started
Extracting the so-what from data exhibits quickly and accurately.
Full Cases — not started
End-to-end case practice using Management Consulted, working up to live mocks.

Each block will link to a detailed log as I work through it. Updated as I go.
